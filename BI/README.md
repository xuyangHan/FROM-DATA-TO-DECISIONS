# Business Intelligence and Data Analysis

This area collects practical learning material for turning raw data into
reliable analysis, useful metrics, visualizations, and business decisions.

The articles progress from foundational BI concepts through SQL, Python,
modelling, experimentation, and interview preparation. They can be read in
numbered order as a learning path or used individually as references.

prepare for interviews.

The later architecture and data engineering articles also connect with the
[Data Engineering area](../DE/), which explores pipelines, platforms, and
